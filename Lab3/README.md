# Лабораторная работа 3: Построение бинарного дерева

## Задача

**Номера варианта**: 4

Напишите на языке Python рекурсивную функцию `gen_bin_tree`, которая будет строить бинарное дерево.

## Решение

Была написана функция `gen_bin_tree`, которая строит бинарное дерево. Она принимает следующие параметры: высоту дерева (`height`), значение корня (`root`), функцию для вычисления левого узла (`left_leaf`) и функцию для вычисления правого узла (`right_leaf`).

Для построения дерева применяется рекурсивный алгоритмы.

## Примечание

Были написаны unit-тесты, для 4 случаев:

1. Высота дерева = `2`, корень = `3`.
2. Высота дерева = `0`, корень = `4` (тест при нулевой высоте).
3. Высота дерева = `-5`, корень = `4` (тест при отрицательной высоте).
4. Высота дерева = `4`, корень = `4`.

Все тесты успешно выполняются.
